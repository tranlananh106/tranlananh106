## What I Do 🎯

1. **Scientific Data Analysis** 🧪  
   I've worked with different types of biological data, from DNA sequences and microbial communities to single-cell RNA-seq datasets. Some examples of my research work include:
   - **Single-cell RNA-seq clustering:** benchmarked community detection algorithms, comparing clustering accuracy, stability, and computational performance across datasets. I'm preparing the analysis code and documentation for GitHub.
   - **Microbiome analysis:** analysed microbial community data using `R`, `QIIME2`, and `phyloseq`.
   - **Molecular taxonomy and phylogenetics:** used sequence data and phylogenetic methods in my research on marine macroalgae. You can find my publications on [Google Scholar](https://scholar.google.com/citations?user=As5kxHMAAAAJ&hl=en&authuser=1).

2. **Statistical Analysis** 📊  
   During my training and statistical consulting work, I've applied statistical methods to research questions involving clinical outcomes, time-to-event data, repeated measurements, and questionnaire validation. I'm interested in making more of these analyses reproducible and sharing examples using public or simulated datasets.

3. **Research Scripts & Data Workflows** 💻  
   I enjoy writing small scripts that make research tasks easier and less repetitive.
   - [Ulva GenBank Toolkit](https://github.com/tranlananh106/ulva-genbank-toolkit) — a repository for Python utilities to prepare and format sequence records for GenBank submission. *In development.*
